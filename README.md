# 总导演手册 · wen-muye-style

一套把「导演意图」翻译成「AI 可执行指令」的 prompt skill：以文牧野的温暖现实主义方法论为主干，落到 Seedream（生图）+ Seedance（图生视频）的实际工作流上。

## 一句话

AI 不理解「凝重」，只理解「机位齐桌面、85 毫米、光从右上方下来、半边脸沉在暗里」。这套手册做的，就是完成这层翻译。

## 它能做什么

- 剧本审读 → 节拍表 → 分镜表
- 关键帧提示词（含参考图分工）
- 视频提示词（机位 / 运镜 / 光影 / 时间轴 / 台词）
- 审图八查（逐张验收）
- 视频投喂 + QC 七条（翻车修复）

## 实战检验

用于 5 分钟 AI 漫剧《红烛》（闻一多题材，山东大学首届 AI 漫剧大赛参赛作品）。一人两周完成全片 30 余个镜头：Seedream 生图 · Seedance 2.5 图生视频 · 即梦 SeedMusic 配乐 · 剪映剪辑。
